# Security policy

The latest release is the supported version. Keep the dashboard behind an
SSH tunnel or an authenticated reverse proxy, and leave the local Signal
RPC private. Select only a Signal group whose members you trust to operate
the bot.

Use **Security → Report a vulnerability** on GitHub when private reporting
is available. If it isn't, ask the maintainer for a private channel without
posting details publicly. Include a version and a minimal synthetic
reproduction. Never attach a live database, keys, tokens, account files,
private feed URLs, or actual group messages.
